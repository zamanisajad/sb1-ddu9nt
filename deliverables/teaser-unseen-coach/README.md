# تیزر ۱۰ ثانیه‌ای «شب‌هایی که شاگرد نمی‌بیند»

- **فایل‌ها:**
  - `teaser_subtitled.mp4`: با زیرنویس روی تصویر
  - `teaser_clean.mp4`: بدون زیرنویس، برای وقتی که فقط نریشن می‌گذارید
- **مشخصات:** ۱۰۸۰×۱۹۲۰ (ریلز)، ۱۰ ثانیه، بدون صدا. نریشن و موسیقی را خودتان اضافه کنید.

## متن نریشن و زمان‌بندی
| زمان | تصویر | نریشن |
|---|---|---|
| ۰ تا ۲٫۳ | دستی که در دفتر می‌نویسد | «شاگردت فقط یه برنامه می‌بینه…» |
| ۲٫۵ تا ۴٫۵ | زنی خسته پشت میز، شب | «نمی‌بینه چند شب بیدار موندی…» |
| ۴٫۷ تا ۶٫۶ | مربی کنار شاگرد، در حال توضیح حرکت | «چند بار یه حرکت رو توضیح دادی…» |
| ۶٫۸ تا ۸٫۴ | ورزشکاری که هالتر را بالای سر نگه می‌دارد | «تا امروز، قوی‌تر از دیروز باشه.» |
| ۸٫۶ تا ۱۰ | لوگو | «کمک مربی. مدیریت کمتر، مربیگری بیشتر.» |

**لحن نریشن:** آرام، گرم و کمی آهسته، مثل درد دل یک همکار. حالت گویندهٔ تبلیغاتی نداشته باشد. موسیقی یک پیانو یا پد ملایم باشد، با صدای خیلی پایین.

## کپشن پیشنهادی
شاگرد فقط برنامه رو می‌بینه؛ شب‌هایی که پاش بیدار موندی رو نه.
این رو بفرست برای مربی‌ای که می‌دونی شب‌ها برای شاگردهاش وقت می‌ذاره 🤍
