## کپشن پیشنهادی

به‌جای استوری تبریک، یه برنامهٔ واقعی برای نوجوون‌ها بچین.
۵۰ ایده با راهنمای قدم‌به‌قدم آماده کردم: برای مربی تک‌نفره، گروه چند مربی، باشگاه، مدرسه و فضای آنلاین.
کلمهٔ «نوجوان» رو کامنت کن تا لینکش رو برات بفرستم 👇
