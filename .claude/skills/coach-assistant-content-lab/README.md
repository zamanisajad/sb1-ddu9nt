# Coach Assistant Content Lab

اسکیل اتاق فکر تولید و ارزیابی محتوای اینستاگرام برند «کمک مربی»، ادغام‌شده با برند بوک.

## فایل‌ها
- `SKILL.md`: فرایند اتاق فکر هفت‌نفره، از ایده تا سناریو، استوری‌بورد، نقد و شبیه‌سازی
- `references/brand-book.md`: شعار، رنگ‌های دقیق، فونت‌ها، لوگو، کاراکترها و لحن برند
- `references/product-claims.md`: قابلیت‌های تأییدشدهٔ اپ و چیزهایی که نباید ادعا شود

## نصب در claude.ai
Settings ← Capabilities ← Skills ← Upload skill، سپس فایل ZIP را انتخاب و اسکیل را فعال کنید.
در مخزن `sb1-ddu9nt` هم در `.claude/skills/coach-assistant-content-lab/` نصب است.
